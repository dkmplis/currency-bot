# Currency Track Bot

Pet project Telegram-бот на **Java + Spring Boot** для отслеживания курсов валют и конвертации сумм по данным банковских API.

Проект сделан как демонстрация навыков backend-разработки:
- проектирование приложения со слоистой архитектурой
- интеграция с внешними API
- обработка пользовательских сценариев в Telegram-боте
- работа с конфигурацией, retry-механизмами и валидацией ввода
- построение расширяемой структуры под новые банки и операции

## Что умеет бот

- показывать курсы валют по выбранному банку
- выполнять конвертацию суммы между валютами
- работать через inline-кнопки Telegram
- обрабатывать ввод суммы пользователем
- повторять запросы к внешним API при временных сбоях

## Идея проекта

Цель проекта — сделать Telegram-бота, который позволяет в несколько шагов:
1. выбрать банк
2. получить актуальные курсы валют
3. выполнить конвертацию суммы

При этом основной упор был сделан не только на рабочий функционал, но и на **понятную и расширяемую архитектуру**, чтобы проект было удобно развивать дальше.

## Архитектура

Проект разбит на независимые слои:

- `config` — конфигурация приложения и внешних клиентов
- `clients` — HTTP-клиенты для банковских API
- `dtos` — DTO для десериализации ответов внешних сервисов
- `services` — бизнес-логика по получению, преобразованию и форматированию данных
- `telegram` — обработка Telegram-сценариев:
    - commands
    - callbacks
    - free text handlers
    - keyboards
- `contexts` — хранение состояния пользователя между шагами сценария
- `utils` — утилиты и константы


## Инженерные особенности

Одной из целей проекта было сделать код удобным для расширения.

- **Устойчивость:** Реализованы механизмы повторных попыток (Retryable) с использованием Spring Retry для обработки временных сбоев API.
- **Интеграционное тестирование:** Использование WireMock для эмуляции поведения внешних банковских API, что позволяет тестировать устойчивость клиента без реальных сетевых запросов.
- **Слоеная архитектура:** Четкое разделение ответственности (Separation of Concerns), исключающее смешивание логики Telegram-бота с бизнес-логикой конвертации.
- **Эффективное кэширование:** Использование Caffeine Cache для снижения нагрузки на внешние API и ускорения работы бота.
- **Гибкость:** Структура проекта позволяет добавлять новые банки и типы конвертаций с минимальными изменениями в существующем коде (Open/Closed Principle).

## Добавление нового банка
Для подключения нового банка достаточно:
- добавить новый `BankType`
- описать DTO ответа нового API
- реализовать HTTP-клиент в `clients`
- реализовать сервис в `services`
- подключить поддержку нужных операций в Telegram flow

## Добавление новой операции
Текущая структура также позволяет относительно просто расширять набор пользовательских сценариев:
- операции описываются отдельно от банковских клиентов
- Telegram-обработчики разделены по типам взаимодействия
- бизнес-логика не завязана напрямую на UI Telegram

За счёт этого новые сценарии можно добавлять без полной переработки существующего кода.

## Запуск проекта с помощью Docker

### 1. Сборка Docker-образа

Выполните команду в корневой директории проекта (где находится `Dockerfile`):

```bash
docker build -t currency-bot .
```

### 2. Запуск контейнера

Для работы бота необходимо передать токен Telegram через переменную окружения `TG_TOKEN`. Замените `ВАШ_ТОКЕН` на реальное значение.

#### Вариант А: Запуск в интерактивном режиме (логи выводятся в консоль)
```bash
docker run -p 8080:8080 -e TG_TOKEN="ВАШ_ТОКЕН" currency-bot
```

## Пользовательские сценарии

### 1. Просмотр курсов валют
- пользователь отправляет `/start`
- выбирает банк
- выбирает операцию `Курс валют`
- бот показывает актуальные значения

### 2. Конвертация суммы
- пользователь отправляет `/start`
- выбирает банк
- выбирает операцию `Конвертация`
- выбирает тип операции
- выбирает исходную валюту
- вводит сумму
- выбирает валюту назначения
- получает результат конвертации
